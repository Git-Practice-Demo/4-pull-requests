# 4-pull-requests

This repository introduces the Pull Request workflow on GitHub.

## Objectives

* Create a feature branch
* Make changes in a branch
* Push a branch to GitHub
* Open a Pull Request
* Respond to review comments
* Update an existing Pull Request
* Merge a Pull Request

## Repository Structure

* `profile.py`
* `students/`

## Task

1. Create a branch named `student/<your-name>`.
2. Inside the `students/` folder, create a new Markdown file named `<your-name>.md`.
3. Add a short introduction about yourself.
4. Commit your changes.
5. Push your branch to GitHub.
6. Open a Pull Request targeting `main`.
7. Respond to any review comments by making additional commits.
8. After approval, merge your Pull Request.

By the end of this exercise, you will have completed a complete GitHub Pull Request workflow.
